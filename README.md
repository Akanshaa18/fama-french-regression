# Fama-French Factor Model Analysis
### STAT 230A — Final Project | May 2026

## Overview
This project investigates which firm-level and market-wide factors explain 
cross-sectional variation in monthly U.S. equity returns. Four nested OLS 
models are estimated, progressing from CAPM to a Fama-French 5-factor model 
augmented with momentum, using 84,348 stock-month observations from the 
S&P 500 over January 2010 – December 2024.

**Research Question:** Which factors significantly explain cross-sectional 
variation in monthly U.S. equity returns, and does augmenting the Fama-French 
three-factor model with momentum and profitability yield a meaningfully better fit?

## Project Structure
```
project/
│
├── data/                    # Generated by load_data.py 
│   ├── returns.csv          # Monthly log returns for S&P 500 stocks
│   ├── factors.csv          # Fama-French factors + momentum
│   ├── panel.parquet        # Long-format merged panel (84,348 × 11)
│   ├── models.pkl           # Fitted OLS models (generated)
│   └── robust_models.pkl    # HC3 robust refitted models
│
├── outputs/
│   ├── figures/             # All plots 
│   └── tables/              # Regression tables, F-tests, VIF 
│
├── load_data.py             # Run ONCE — fetches and saves all data
├── models.py                # Fits four OLS models, saves regression table
├── diagnostics.py           # Assumption checks, saves plots and VIF table
├── alpha_analysis.py        # Alpha analysis across models, saves plot
├── eda.ipynb                # Exploratory data analysis notebook
├── bashCommands.sh          # End-to-end run script
└── .gitignore
```

## How to Run

> **Important:** Scripts must be run in order. Each script depends on 
> outputs saved by the previous one.

```bash
# Step 1 — Download and save all data (run once)
python load_data.py

# Step 2 — Fit all four OLS models
python models.py

# Step 3 — Run assumption diagnostics
python diagnostics.py

# Step 4 — Alpha analysis across models
python alpha_analysis.py
```

Or run everything at once:
```bash
bash bashCommands.sh
```
